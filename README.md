# Interface_Games2
Projeto de desenvolvimento de interface para um jogo de vestir personagens 3D, desenvolvido para a disciplina Interfaces II do curso de Jogos Digitais.


**Informações gerais**

Nome do jogo: (Ainda sem definição)

Gênero: Vestir, simulação casual e personalização de personagens

Plataforma: PC (Windows)

Engine: Unity


**Conceito do jogo**

O jogador terá acesso a um personagem 3D que poderá ser personalizado por meio da seleção de diferentes peças de roupa, calçados e acessórios.


**Público-alvo**

O jogo é direcionado a adolescentes e adultos que gostam de moda, personalização de personagens e cozy games. 

**Estilo visual e direção de arte**


A direção de arte combinará formas suaves, cores harmoniosas e iluminação delicada para criar uma experiência visual acolhedora. As roupas e os acessórios poderão explorar estilos.

A interface seguirá uma identidade visual fofa e moderna, com painéis organizados, ícones delicados e elementos gráficos inspirados em estrelas, corações e brilhos, sem comprometer a legibilidade.
